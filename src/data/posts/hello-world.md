## 为什么写博客

输出是最好的学习方式。把学到的知识写成文章，不仅能加深理解，
还能帮助遇到同样问题的人。这是我的第一篇博客，也是这个博客站的起点。

## 这个博客有什么

- **技术分享**：React、TypeScript、CSS 等前端技术
- **项目复盘**：记录做过的项目和踩过的坑
- **学习笔记**：读书、看文档时的摘录与思考

## 一段示例代码

博客支持代码高亮，下面是一段 JavaScript：

```javascript
function greet(name) {
  // 模板字符串拼接问候语
  const message = `你好，${name}！`;
  console.log(message);
  return message;
}

greet('世界');
```
